
## 📞  Sampark - Real-Time Video Calling with Chat


**Sampark** is a sleek and stylish real-time video calling web application with integrated live chat, animated cursor effects, and a beautiful modern UI. It offers a seamless communication experience with just one click.

---

### 🚀 Features

* 🔴 **Real-time Video Calling**
* 🎤 **Toggle Audio/Video**
* 💬 **Instant Chat Messaging**
* 🎨 **Interactive Cursor Tail Effect**
* 💡 **Animated Loader and Buttons**
* 📱 **Responsive & Mobile-Friendly Design**
* 🔐 **Peer-to-Peer Connection (via WebRTC & Socket.IO)**

---

### 🖥️ Tech Stack

* **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
* **WebSocket**: [Socket.IO](https://socket.io/)
* **Real-time Media**: WebRTC
* **Styling**: Gradient UI, FontAwesome, Animated Components
* **Backend**: Node.js with Express (required for signaling server - not included here)

### 💡 How It Works

* **WebRTC**: Handles real-time audio and video peer-to-peer communication.
* **Socket.IO**: Used for signaling between peers to exchange connection details.
* **Chat**: Sent via sockets and rendered with smooth animations.
* **Particle Cursor**: Custom canvas rendering for aesthetic interaction.
